# Orbis landing page

A simple static landing page for Orbis, an Islamic Cultural Centre initiative.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder.

## Deploy to Netlify

Drag this entire `orbis` folder into the deploy area on the Netlify Projects page. No build command is required.

For automatic updates, place this folder in a GitHub repository and import that repository as a new Netlify project.
